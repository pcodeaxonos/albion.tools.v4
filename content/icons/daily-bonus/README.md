# Albion Craft Dashboard – Asset Pack

Bu paket, gönderilen dashboard tasarımını Codex'te yeniden kurmak için gerekli görsel parçaları içerir.

## Klasörler
- `reference/` – tam tasarım referansı
- `items/` – T4/T5/T6 item görselleri
- `materials/` – hammadde ikonları
- `decor/` – tier başlıklarının sağındaki dekoratif silah dokuları
- `ui-icons/` – küçük arayüz ikonları (SVG)
- `manifest.json` – asset isimleri ve kısa kullanım notları

## Kodlarken
- Kart border, gradient, rank badge ve glow efektlerini CSS ile üret.
- T4: mavi, T5: kırmızı, T6: amber/gold accent kullan.
- Item görsellerini yaklaşık 72–84 px göster.
- Kart içindeki metrikleri rasterlaştırma; HTML metni olarak bırak.
- Font dosyası özellikle eklenmedi. `Inter, "Segoe UI", system-ui, sans-serif` uygundur.

## Not
Item/material görselleri gönderilen görsel tasarımından crop edilmiştir; bu yüzden mockup ile birebir görsel uyum sağlar.
